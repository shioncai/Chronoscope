# Chronoscope

> 一台"观时之镜"——在同一条时间轴上同时容纳「138 亿年前」和「今天下午」。

Chronoscope 是一个记录事件的 web app，但不是普通记事本。它的核心是一条**跨尺度时间轴**：从地质 / 宇宙级别的大事件，到某个下午发生的小事件，都能落在同一条轴上对比先后与跨度。

## 特点

- **跨 ~12 个数量级的时间**：自制的"十进制年 + 精度档位"时间模型，支持公元前、地质年代（ka / Ma / Ga），下至秒级。
- **模糊与残缺时间**：可记录"约 38 亿年前""1990 年代"这类模糊时间，显式误差范围，以及只有起点或只有终点的事件。
- **双轴可视化**：Canvas 渲染的线性细节轴 + 一屏纵览的线性总览条；拖动"取景窗"在总览与细节间精细比对，总览自身也能缩放聚焦到某个尺度。
- **列表视图**：与时间轴共享筛选 / 排序 / 搜索状态；多列展示、可勾选、批量移动 / 打标签 / 删除。
- **可嵌套分类 + 多标签**：文件夹树（可拖拽调整层级与排序）或标签（支持"与 / 或"）筛选；全文搜索；事件之间可关联；备注支持 Markdown。
- **回收站**：删除为软删除，可恢复或永久清除；删除文件夹会级联删除其子级与事件，恢复事件时会一并还原它所属的文件夹层级。
- **本地优先、数据自有**：纯客户端 PWA，无后端、无账号、完全离线可用；数据存在浏览器 IndexedDB（Dexie）里，每条记录带 HLC 时间戳，为将来的多端同步预留。
- **昼夜双主题**：精密仪器 / 历表气质，颜色随时间深度变温。

## 状态

开发中，主体功能已实现：跨尺度时间轴、列表视图、事件编辑器、分类 / 标签 / 搜索、回收站、昼夜主题。领域、状态与渲染逻辑有 300+ 单元测试覆盖。

## 技术栈

React 19 + TypeScript（strict）+ Vite · IndexedDB（Dexie）· PWA · Canvas + DOM 混合渲染时间轴 · Vitest。

## 本地开发

```bash
npm install
npm run dev      # 启动开发服务器
npm test         # 运行单元测试（Vitest）
npm run build    # 类型检查（tsc）+ 生产构建
npm run lint     # ESLint
```

## 架构原则

纯客户端、本地优先；模块高度解耦，每层只依赖下一层：

- **领域层**（`src/domain`，时间 / 模型）零依赖、纯函数，是格式化 / 解析 / 刻度的唯一来源；
- **存储**（`src/data`）藏在仓储接口之后——应用注入 Dexie，测试注入内存实现；删除为墓碑式软删除；
- **状态层**（`src/state`）是自制的响应式 store，每次改动同时落库与更新内存；
- **视图**（`src/ui`，列表与时间轴）是同一份筛选状态的平等消费者，时间轴先用纯函数构建"场景"、再绘制到 Canvas。

功能模块可独立增减。
